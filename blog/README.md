# Blog content

Posts live in `posts/` as Markdown files. Add each filename to `index.txt` to publish it and control its position.

Every post starts with front matter:

```markdown
---
title: Post title
date: September 4, 2026
summary: Short text shown on the blog card.
banner: banners/my-banner.webp
tags: Design, Kotlin
---

Your Markdown starts here.
```

`banner` is optional. Put banner images in `blog/banners/`; landscape images around 1600×900 work well. Supported body elements include headings, paragraphs, bold text, inline code, links, bullet lists, quotes, dividers, and fenced code blocks.
